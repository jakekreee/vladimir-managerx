# VK Chat Manager Bot

Бот для управления беседами ВКонтакте с системой ролей и командами.

## Развертывание на Amvera

1. **Зарегистрируйтесь** на [amvera.ru](https://amvera.ru) и создайте новый проект.

2. **Подготовьте репозиторий**:
   - Создайте репозиторий на GitHub (или GitLab) и загрузите все файлы из этого проекта.
   - Убедитесь, что в корне есть `bot.py`, `database.py`, `config.py`, `requirements.txt`.

3. **Настройка переменных окружения** (или правка `config.py`):
   - В `config.py` укажите:
     - `TOKEN` – токен группы ВКонтакте.
     - `GROUP_ID` – ID группы (число).
   - Если не знаете `BOT_ID`, оставьте `None` – бот определит автоматически.

4. **В панели Amvera**:
   - Подключите репозиторий.
   - Выберите стек **Python**.
   - Укажите команду запуска: `python bot.py`
   - Нажмите «Задеплоить».

5. **Проверка**:
   - После успешного деплоя бот запустится.
   - Добавьте бота в беседу – он пришлёт приветственное сообщение.
   - Выдайте боту права администратора в беседе (для команд `kick`, `ban` и др.).
   - Введите `/start` для активации беседы.

## Команды

Все команды начинаются с `!` (например, `!stats`).

Список доступных команд зависит от вашей роли. Полный список можно увидеть командой `!help`.
